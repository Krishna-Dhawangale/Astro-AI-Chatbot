1. EXECUTIVE SUMMARY & DECISION TREE
--------------------------------------------------------------------------------
This phase performs an objective, scientific comparison across all 3 available 
generations of the domain classifier WITHOUT changing any production router files, 
overwriting model artifacts, or modifying reasoning engines.

DECISION TREE STRATEGY:
                    Compare all models
                           │
                           ▼
                ┌─────────────────────┐
                │ Is one model clearly │
                │ better overall?     │
                └──────────┬──────────┘
                      YES  │  NO
                           │
                ▼          │          ▼
          Use best model   │    Check complementary
          after approval   │    strengths
                           │          │
                           │          ▼
                           │    Consider selector/
                           │       ensemble
                           │          │
                           └──────────┘

- If one model (e.g. V3) is consistently superior across overall Accuracy, Macro F1,
  and domain F1 scores, recommend making that model the active production model
  (simple drop-in replacement after approval).
- Only if models display complementary strengths across different domains will an
  ensemble/selector layer be presented for approval.

3. SCIKIT-LEARN COMPATIBILITY & INTEGRITY CHECKS
--------------------------------------------------------------------------------
The comparison tool executes 10 validation checks for EVERY model pair:
1. Model file existence.
2. Vectorizer file existence.
3. Metadata file existence.
4. Model loadable via joblib.
5. Vectorizer loadable via joblib.
6. Feature shape compatibility.
7. model.classes_ attribute integrity.
8. Vectorizer transform output compatibility.
9. Prediction functionality.
10. Probability distribution generation.

Runtime sklearn version warnings (estimators unpickled from 1.6.1 in 1.9.1) are 
trapped and logged in the evaluation report without modifying any files.


4. COMPREHENSIVE REGRESSION DATASET
--------------------------------------------------------------------------------
All models are evaluated on the exact same labeled dataset:
- Health Regression Questions (8 items: energy, weakness, sleep, fatigue)
- Relationship Regression Questions (5 items: ask out, crush, relationship, couple)
- Career Test Set (5 items: promotion, job change, business growth)
- Finance Test Set (5 items: income increase, wealth, investments)
- Other / General Test Set (5 items: nakshatra definition, chart basics)
- Additional labeled samples from qa_database.json & project test files.


5. EVALUATION METRICS & CONFIDENCE RELIABILITY
--------------------------------------------------------------------------------
For every model version:
- Overall Metrics: Accuracy, Precision, Recall, Macro F1, Weighted F1.
- Domain-Specific Metrics: Per-domain Precision, Recall, F1 for:
  * career
  * finance
  * health
  * marriage
  * other
- Confidence Reliability & Calibration:
  * Average confidence on CORRECT predictions vs INCORRECT predictions.
  * Checks if high confidence correlates with actual accuracy.
- Per-Question Output: Show prediction + confidence from every model for every query.


6. ZERO PRODUCTION IMPACT
--------------------------------------------------------------------------------
- CREATE: compare_domain_models.py (Standalone comparison script).
- DO NOT modify domain.py, predictor.py, pipeline.py, or any production router files.
- Deliver comprehensive comparison report with scientific recommendations.
